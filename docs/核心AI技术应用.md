# 《囊泡漂流 EXO-PINCH》核心 AI 技术应用

> 赛道：AI 原生游戏 —— AI 是核心玩法本体，去掉 AI，游戏不成立。

## 一句话定位

九个关卡中没有一关是手工写死的：每一关的物理规则、膜形态、机制组合、目标数值与叙事文案，都由大语言模型实时生成的「关卡基因组（LevelGenome）」驱动。玩家每次按 `N`，AI 重新生成一整套关卡——**AI 不是外挂功能，而是关卡的「设计师、导演与编剧」**。

---

## 1. AI 生成关卡基因组（LLM LevelGenome）——AI 即核心机制

**做什么**：每一关开始前，把该关的「设计蓝图」（机制约束，如第 5 关必须排队装载、第 8 关必须有核膜）、玩家能力画像、随机种子一起交给 LLM，要求输出一份严格 JSON 的关卡基因组，包含：

| 基因组字段 | 驱动的游戏内容 |
| --- | --- |
| `physics` | 细胞外/内的粘滞度、弹性、湍流、弹射力度上限 |
| `scale` | 外泌体与细胞的尺寸比（巨人国尺度感） |
| `membrane` | 膜厚度、薄区比例、可渗透速度阈值 |
| `goals` | 需装载的信息包数量、信号窗口时限、起始能量、能量流失率 |
| `counts` | 细胞器、ATP、危险物、装载站数量 |
| `name / brief / hint` | 关卡名、氛围文案、操作提示 |

**为什么这是 AI 原生而不是 AI 增强**：九关的布局、数值、文案 100% 由生成结果决定，没有一张手工关卡表；移除 LLM，游戏没有任何关卡可玩。

**工程关键——幻觉免疫（结构化输出 + 校验层）**：LLM 输出不直接进引擎，先经过 `validateGenome()`：把任意输出裁剪进物理合法区间（例如粘滞度钳制在 0.05–2.0），并由蓝图**强制对齐机制开关**（LLM 无权削弱关卡的核心机制）。因此无论模型输出什么，产出的关卡 100% 可运行、可通关——这是「AI 生成内容」与「确定性游戏引擎」之间的安全边界。

## 2. 双大脑架构：云脑 + 本地生成脑（CloudBase AI，浏览器直连）

- **云脑**：通过 CloudBase JS SDK 在浏览器内直连托管大模型池（`ai.createModel("cloudbase")`，模型置于 `model` 字段），无需自建后端与密钥下发。
- **本地脑**：与云脑共用同一套基因组 Schema 的种子驱动程序化生成器，按难度曲线 + 玩家画像产出同构基因组。
- **自动降级链**：未配置环境 / 未登录 / 调用失败 / 超时 → 无缝切换本地脑。玩家永远不等加载，评审演示零风险；接入云脑后即获得真正的无限生成多样性。

## 3. AI 导演（Director）——实时叙事与节奏编排

- **事件驱动生成**：撞膜过猛、顺序插队、能量告急、信号窗口将关闭、通关/降解等 10 类游戏事件，实时触发 LLM 生成一句 ≤18 字的个性化解说。
- **双通道输出**：本地模板台词**同步即时返回**（0 延迟手感），云端生成结果**异步覆盖**（个性化表达）——兼顾体验与多样性，解决 LLM 延迟破坏游戏节奏的通用难题。

## 4. 玩家画像闭环——自适应难度生成

胜负数据实时写入玩家画像（`profile.adjust`）：连败自动调低生成难度、连胜调高，并注入下一关的生成 Prompt。**AI 不只生成关卡，还根据「你是谁、玩得怎样」决定下一关长什么样**——形成「游玩 → 画像 → 再生成」的闭环，这是传统手工关卡无法做到的。

## 5. AI 生成美术资产

主角外泌体的「QQ 糖捏捏」原画由文生图模型生成（半透明果冻质感 + CD63/CD81 四跨膜蛋白的科学细节），并以此设定统一渲染风格（Canvas 程序化复现软糖高光与形变）。可扩展：每关卡面由基因组 `brief` 喂给图像模型逐关生成。

## 6. 种子化确定性——AI 生成 × 可复现竞速

基因组生成以种子为随机源：**同一 seed 完全复现同一关卡**。AI 的无限生成与竞技游戏必需的可复现性兼得——玩家可分享种子挑战同一关卡竞速，也可一键换种子进入全新关卡。

## 与评审维度的对应

| 评审维度 | 本作的回答 |
| --- | --- |
| **创新性（体验独特性）** | AI 生成的不是贴图或对话文本，而是「可直接运行的物理关卡」：LLM 输出直接决定重力、粘滞、膜形态与通关条件 |
| **可玩性（趣味与完成度）** | 校验层保证生成关卡 100% 可玩；九关机制递进（弹射→渗透→排队→双膜→接力）提供完整难度曲线 |
| **技术实现（使用合理性）** | LLM 结构化输出 + 幻觉免疫校验 + 云/本地双脑自动降级 + 种子化复现，每一层 AI 都解决具体工程问题，无「为 AI 而 AI」 |
| **AI 使用层级** | **AI 原生**：AI 生成关卡、导演叙事、自适应难度三位一体；移除 AI 后游戏不成立 |
