## 操作

| 操作 | 说明 |
| --- | --- |
| 拖拽后松手 | **弹弓式**：按住画面任意处，朝「想去的反方向」拖，拖得越远弹得越猛，松手飞出（首次进入第 1 关有动画演示） |
| 按住鼠标 / 空格 | 渗透过程中加速挤膜（更费能量） |
| `R` | 重开本关（**同一张图**：seed 不变，完全复现，用于重试练手） |
| `N` | 换种子重开本关（**换新图**：AI 按新 seed 重新生成细胞布局、信息包位置与参数） |
| 菜单「重掷星盘」 | 只换整趟旅程的 `baseSeed`，不重载当前关；影响之后载入的每一关 |

- 外泌体外圈的光环表示**当前速度能否渗进膜**：青色 = 可以挤进去，红色 = 会被弹开。
- 膜上青色段是**薄区**（最容易进），橙色带编号是**受体**（需按编号顺序），绿色箭头是**出口**。
- 撞膜太猛会被弹开并损失能量；够慢的话，连厚膜区也能硬挤进去，只是又慢又费能量。
- 能量随时间与运动流失，吃 ATP（黄色三磷酸颗粒）补充，ATP 会再生。信号窗口（倒计时）关闭即失败。

## AI 原生架构

关卡不是手写常量，而是由 AI 实时生成的**关卡基因组（LevelGenome）**：

```
LEVEL_BLUEPRINTS（设计意图/机制约束）
        │
        ├─ CloudBrain（CloudBase AI，可选）── generateText(JSON)
        │        失败 / 未配置 → 自动降级
        └─ LocalBrain（内置生成脑，种子驱动，离线可用）
        │
   validateGenome()  ← 校验数值域 + 强制对齐蓝图机制
        │
   World 构建器（种子化布局：细胞链、核、细胞器、装载站、信息包、ATP、危险物）
        │
   Game（物理步进 / 渗透状态机 / 目标判定）+ Director（AI 导演实时提示）
```

- **双脑可切换**：在菜单填入 CloudBase 环境 ID 点「连接云脑」即可让大模型产出关卡参数与文案；未登录、未开通或调用失败时自动降级到本地生成脑，游戏永不可卡死。
- **基因组自校验**：`validateGenome` 会把 LLM 的任意输出裁剪进合法区间，并强制保留蓝图要求的机制（例如第 8 关必须有核、第 5 关必须排队）。
- **AI 导演**：根据撞膜过猛、能量告急、插队、时间不足等事件生成即时提示，本地模板即时返回，云脑结果异步覆盖。
- **自适应难度**：连败降低 `profile.adjust`，连胜提高，下一关生成时难度随玩家水平浮动。
- 换种子（`N`）会用新 seed 重新生成一整套关卡布局与文案，同一 seed 完全可复现。

## AI 生成美术资产

主角外泌体的「QQ 糖捏捏」原画由文生图模型生成（半透明软糖 + CD63/CD81 四跨膜蛋白 + 内部 cargo 光带），按游戏状态产出四张精灵：

| 文件 | 状态 | 触发条件 |
| --- | --- | --- |
| `assets/exo-normal.png` | 常态漂浮 | 默认 |
| `assets/exo-squeeze.png` | 被膜挤压、横向压扁 | 渗透中 / 剧烈碰撞形变 |
| `assets/exo-cargo.png` | 内部可见 miRNA 螺旋与蛋白颗粒 | 已携带信息包 |
| `assets/exo-low.png` | 失色、裂纹、ATP 火星外泄 | 能量 < 25 / 被降解 |

「巨人国」的巨物与能量颗粒同属一套视觉语言，同样由文生图生成：`organelle-mito`（山一样的线粒体）、`organelle-er`（内质网潴泡）、`organelle-golgi`（高尔基体层叠）、`organelle-vesicle`（溶酶体/囊泡）、`organelle-nucleus`（双膜核，用于第 8 关第二道门）、`pick-atp`（ATP 能量颗粒）。所有精灵共用 `prepareSprite()` 自动去背与包围盒对齐，加载失败自动回退到程序化绘制。

运行时 `prepareSprite()` 采样四角估计背景色做**自动去背**，并计算主体包围盒把原画精确对齐到外泌体的物理碰撞半径；未加载完时回退到程序化软糖（零等待）。关卡卡与主菜单头像复用同一原画（CSS `mix-blend-mode: screen` 融入暗色卡片）。

## 免疫 / 病原敌人（AI 原生机制随关卡缩放）

敌人的**种类与数量**由基因组 `mechanics.immune` 决定，难度越高的关卡自动叠加更多威胁——生成脑一次性决定"这关有几只、都是谁"，而非手写：

| 等级 | 敌人 | 行为 |
| --- | --- | --- |
| 1 | 巨噬体 | 缓慢巡逻、把外泌体弹开并吞掉少量以太 |
| 2 | + NK 细胞 | 锁定目标蓄力（红色预警圈）→ 高速直线冲刺 |
| 3 | + 诱捕网 | 中性粒细胞胞外诱捕网：静态粘滞区，进入后减速并持续掉以太 |
| 4 | + 病毒 | 更小更快，频繁短促锁定冲刺；撞中若携带密文会夺走一份 |
| 5 | + 细菌 | 缓慢游弋逼近玩家，体表释放毒素云（区域粘滞+掉以太），撞上毒性侵蚀 |

出现节奏（对应九关主题）：L4/L5/L6 巨噬体 → L7 炎症灶加 NK → L8 核域加病毒 → L9 终章全员 + 细菌。所有敌人共用外泌体同款软糖视觉语言（文生图生成），加载失败时回退程序化绘制。
